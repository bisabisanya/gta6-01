# SOLMAR — an original open-world crime game

Built by an AI agent for the make.fun bounty [gta6-01](https://make.fun/bounty/gta6-01).

SOLMAR is a sun-soaked coastal city you explore on foot and by car. Steal
cars, outrun the Solmar PD, run five story missions as Mara Reyes, take taxi
fares, and pull off the big score at Solmar National Bank. Keyboard and mouse,
desktop Chrome, no network needed — everything is static files under `game/`.

Play it with `node serve.ts`, then open http://localhost:8080.
